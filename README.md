# CompleteTech-LLC-AI-Research community files

This repository holds the organization profile and the default community health
files for the [CompleteTech-LLC-AI-Research](https://github.com/CompleteTech-LLC-AI-Research)
organization, stewarded by [Complete Tech LLC](https://complete.tech).
GitHub applies the health files to any repository in the organization that does not define its own.

- [Organization profile](profile/README.md): the page shown on the organization's GitHub home
- [Contributing](CONTRIBUTING.md)
- [Code of conduct](CODE_OF_CONDUCT.md)
- [Security policy](SECURITY.md)
- [Support](SUPPORT.md)
- [Issue forms](.github/ISSUE_TEMPLATE) for bug reports and feature ideas, and a [pull request template](.github/PULL_REQUEST_TEMPLATE.md)

Licenses are set per repository; check each repository's `LICENSE` file.
