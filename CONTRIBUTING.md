# Contributing

Thanks for helping. These notes apply to every repository in this organization
unless that repository has its own `CONTRIBUTING.md`.

1. **Open an issue first** for anything beyond a small fix, so we can agree on scope.
2. **Keep pull requests small and focused.** One change per PR, with a clear description of what changed and why.
3. **Run the repository's own checks** (see its README) and say in the PR what you ran and what you did not.
4. **Be evidence-first.** Do not add claims, metrics, or status to docs that you have not verified; note limits honestly.
5. **Never commit secrets**, credentials, tokens, private hostnames, or personal data. If you find one, report it under [SECURITY.md](SECURITY.md) instead of opening a public issue.
6. **Licensing.** Contributions are accepted under the license of the repository you contribute to. Check its `LICENSE` file; if there is none, ask in an issue before contributing.

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).
