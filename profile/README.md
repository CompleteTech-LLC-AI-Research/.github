# CompleteTech LLC AI Research

Open research tools and experiments on AI coding agents, context management,
and evaluation, stewarded by [Complete Tech LLC](https://complete.tech).
Updates on X: [@CompleteTechLLC](https://x.com/CompleteTechLLC).

## Where to start

- [`jev-context-fabric`](https://github.com/CompleteTech-LLC-AI-Research/jev-context-fabric): local-first, source-backed memory layer for coding agents, with a zero-dependency installer for eight harnesses.
- [`JEV-Paper-Radar`](https://github.com/CompleteTech-LLC-AI-Research/JEV-Paper-Radar): reads new arXiv papers each morning and surfaces the few worth reading.
- [`systemone-compiler`](https://github.com/CompleteTech-LLC-AI-Research/systemone-compiler): declare a decision, compile typed Jev questions, measure them, ship a JSON program.
- [`beyond-the-token-bottleneck`](https://github.com/CompleteTech-LLC-AI-Research/beyond-the-token-bottleneck): an Obsidian research wiki on latent-space reasoning and inter-agent communication.

## Honest limits

Several of these projects are experimental. For example, `jev-prune-kit` is
marked experimental and not live-host tested, and `pokemon-harness` reports its
current release candidate as `PARTIAL`, not production-ready. Each repository's
README is the authority on its own status; this page makes no claims beyond them.
